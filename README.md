# 마음결 — 감정 일기 웹서비스

하루의 감정과 짧은 일기를 달력에 기록하고, 기간별 감정 분포와 지난 기록을 돌아보는 모바일 중심 웹서비스입니다.

## 주요 기능

- 날짜 선택 및 월 이동 달력
- 4가지 감정과 120자 일기 저장
- 기록 수정·삭제 및 기록일 표시
- 최근 7일/30일/전체 감정 통계
- 감정별 지난 기록 필터
- 총 기록 수, 연속 기록일, 가장 잦은 감정 요약
- `localStorage` 기반 브라우저 내 데이터 보존
- 모바일/데스크톱 반응형 UI와 키보드 접근성

## 실행

별도 설치 없이 정적 서버로 실행할 수 있습니다.

```bash
npx serve .
```

또는 `index.html`을 브라우저에서 열어도 동작합니다.

## 폴더 구조

```text
index.html
styles.css
app.js
```

## 제출 메모

- 서비스명: 마음결
- 한 줄 소개: 매일의 감정을 기록하고 나만의 마음 패턴을 발견하는 감정 일기
- 데이터는 사용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.
